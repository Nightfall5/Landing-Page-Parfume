## 🖼️ Mengganti Gambar

### Cara Mudah:

1. Ganti file gambar di folder `images/` dengan nama yang sama
2. Atau edit path di `scripts/main.js` untuk menggunakan gambar baru

### Format Gambar yang Disarankan:

- **Produk**: 400x300px (JPG/PNG)
- **Hero**: 500x600px (JPG/PNG)
- **About**: 600x400px (JPG/PNG)
